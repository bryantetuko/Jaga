# 👶 Jaga

UI/UX prototype of a babysitter marketplace application that helps parents find trusted babysitters through flexible booking and safety-focused features.

[![Figma](https://img.shields.io/badge/Figma-000000?style=for-the-badge&logo=figma&logoColor=white)](https://www.figma.com/design/tketOYakn6cxSd015CmwdH/Jaga?node-id=301-1034&t=w7iZaEnSsH8ypu5I-1)

---

## 📱 Overview

Jaga is a mobile UI/UX prototype designed to help parents find and book trusted babysitters based on their needs.

The application focuses on making babysitter discovery and booking more convenient while providing safety-focused features to help parents make informed decisions.

The interface was designed in **Figma**, with an emphasis on simplicity, trust, and ease of use.

---

## ✨ Features

- **Babysitter Discovery** — Browse and explore available babysitters.
- **Babysitter Profiles** — View babysitter information to help parents make informed decisions.
- **Flexible Booking** — Book babysitting services based on the parent's needs and schedule.
- **Safety-Focused Features** — Provide information and features designed to build trust between parents and babysitters.
- **Simple Navigation** — Designed with a straightforward and intuitive mobile experience.

---

## 🎨 Design

Jaga was designed as a mobile-first UI/UX prototype using **Figma**.

The design focuses on:

- Clear and intuitive navigation
- Trust and safety
- Easy babysitter discovery
- Flexible booking experience
- Clean and accessible interface
